# File Reasons Support

File Reasons helps you remember why you’re keeping a file or folder
and when to review it.

## Contact

with “File Reasons” in the subject.

For a problem report, include:
- Your macOS version and File Reasons version
- What you were doing
- What you expected and what happened
- Any error message

You don’t need to send us your tracked files or folders.

## Common questions

### Does File Reasons move or delete my files?

No. It stores a reference to the item, your reason, review date,
and optional release condition.

### How do I add a file or folder?

Click Add Item and choose a file or folder, or drag one item from Finder into the main window. Enter your reason, then choose a review date or select Remember indefinitely. Click Add reason to save.

Drag and drop supports one item at a time.

### Archive and restore items
Archive an item when you no longer need to actively track it. Its reason, saved review date, and file reference remain available in Archive, and its review reminders stop.

Choose Restore to return it to All Items. Its original review date is preserved. Items due today or overdue also appear in Due for Review. Future reminders resume when reminders are enabled.

Archiving does not move or delete the original file or folder.

### How do I permanently remove a record?

Open Archive, open the item’s Actions menu, and choose Stop tracking. A confirmation appears before the record is removed.

Stop tracking permanently removes the saved reason, review date, release condition, and file reference from File Reasons. This cannot be undone. The original file or folder is not deleted.



### Where are my records stored?

Records and preferences are stored locally on your Mac.
The app does not upload them to our servers.

### How do reminders work?

Enable review reminders in Settings and allow notifications. Your chosen reminder time applies to active items with a review date. Items set to Remember indefinitely and archived items do not receive reminders.

A reminder is scheduled only when its review date and chosen time are still in the future. Overdue items remain visible in Due for Review.

### What if an item cannot be found?

Use Reconnect item from its Actions menu to select it again.
