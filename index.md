# File Reasons Support

File Reasons helps you remember why you’re keeping a file or folder
and when to review it.

## Contact

Email [rohitsaisatya.apps@proton.me](mailto:rohitsaisatya.apps@proton.me)
with “File Reasons” in the subject.

For a problem report, include:
- Your macOS version and File Reasons version
- What you were doing
- What you expected and what happened
- Any error message

Please remove personal information from screenshots.
You don’t need to send us your tracked files or folders.

## Common questions

### Does File Reasons move or delete my files?

No. It stores a reference to the item, your reason, review date,
and optional release condition. Stopping tracking removes the
record and its reminder, not the original file or folder.

### Where are my records stored?

Records and preferences are stored locally on your Mac.
The app does not upload them to our servers.

### How do reminders work?

Enable review reminders in Settings and allow notifications.
The reminder time applies to all tracked items; each item has
its own review date.

### What if an item cannot be found?

Use Reconnect item from its Actions menu to select it again.
